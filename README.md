# bal-bala1 балабақшасы — лендинг

Next.js 15 · TypeScript · Tailwind CSS 4

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Логотип и фото

- **Логотип:** положите файл в `public/` как `logo.png` (или `logo.svg`, `logo.webp`, `logo.jpg`, `logo.jpeg`).
  Он появится в header и footer автоматически. Пока файла нет — показывается аккуратный значок «B».
- **Галерея:** фото в `public/images/` с именами `image1.jpg`, `image2.jpg`, `image3.jpg` …
  (подходят .jpg, .jpeg, .png, .webp, .avif). Новые фото подхватываются автоматически по номеру.
  Галерея раскладывает их рядами по 2 и 3 фото; каждое фото показывается целиком, в своих пропорциях — ничего не обрезается.
- **Фото первого экрана:** `public/images/hero.jpg` (или .jpeg/.png/.webp). Если его нет — берётся `image1`.
- **Фото в «Біз туралы»:** следующее по номеру фото из галереи.
  В фигурных рамках (первый экран, арка) фото тоже показывается целиком, а свободное место заполняет его размытая копия.
- Подписи (alt) к отдельным фото — в `imageOverrides` в `lib/content.ts`.

После добавления фото на продакшене пересоберите сайт (`npm run build`).

## Где что менять

- `lib/site.ts` — название, адрес, телефон, режим работы.
- `lib/content.ts` — меню, карточки, артықшылықтар.
- `components/sections/*` — секции страницы; `components/layout/*` — header, footer, логотип.
